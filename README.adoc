# Majsoul-to-NAGA
=Use Mahjong Soul Logs with NAGA AI analysis
:experimental:

== Summary
Capture Mahjong Soul logs from a replay using browser Greasemonkey script and
convert to format accepted by NAGA's custom game analysis.

Mahjong Soul no longer exposes the `GameMgr`/`app` globals this script used to
call. The userscript now hooks `window.WebSocket` at page load, captures the raw
`fetchGameRecord` replay response, converts it in-browser, and submits the
per-round custom-game payload to NAGA when you press kbd:[S].

== Instructions (Browser)
=== Install tampermonkey extension on your browser
https://www.tampermonkey.net/[Download it here]

=== Install `downloadlogsnaga` script
Add https://github.com/honvl/Majsoul-to-NAGA/raw/master/downloadlogsnaga.js[this script] to Tampermonkey.

The script uses Tampermonkey permissions for Mahjong Soul domains and
`naga.dmv.nico`. It reads your existing NAGA browser session only to submit the
custom-game request.

=== Overview of how to use NAGA
Find an overview of how to pay for and use NAGA's service https://pathofhouou.blogspot.com/2021/08/training-tool-naga-replay-review.html[here]

=== Submit the log
Login to Mahjong Soul, open the 4-player replay you want to review, and stay
logged in to NAGA in the same browser. Press kbd:[S] after the replay is loaded.
The script converts the replay, submits it to NAGA's custom analysis API, and
shows progress in a small on-page toast. NAGA points are charged by the round
for custom games.

== Development
Run the converter fixture test with:

----
npm test
----

Run the full local check with:

----
npm run check
----
